# sezam

A set of small files from a first-year exercise: 10 HTML pages, 10 text files, 10 PNG images and 7 SVG figures.

University coursework from my Computer Science studies at UWM (2020–2024). I wrote the code by hand; the commit history is unchanged. This README was added in November 2026.

Years of work: 2020–2021 (first commit on 24 November 2020, last commit on 5 January 2021).

## Contents

- `litera0.html`–`litera9.html`: pages with one bold letter each.
- `cyfra0.txt`–`cyfra9.txt`: the English names of the digits ("Zero", "One", …).
- `ryc0.png`–`ryc9.png`: images.
- `figura0.svg`–`figura6.svg`: SVG figures.

## Running

The repository holds data files, not a program, so there is nothing to run.
